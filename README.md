1
建立公開儲存庫： 登入 GitHub，點選右上角「+」→「New repository」，輸入 Repository Name，勾選 Public 並點擊「Create repository」。
2
拖曳上傳檔案： 於新建立的儲存庫頁面，點擊 uploading an existing file 連結，將本機的 index.html、CSS、JS 檔案與圖片資料夾拖曳至網頁中，最後點選「Commit changes」。
3
開啟 Pages 服務： 進入儲存庫「Settings」→ 左側「Pages」→ 於 Build and deployment 的 Branch 將 None 切換為 main，路徑保持 /(root)，點擊「Save」。
4
等待自動部署： CI/CD 流水線約需 1 至 3 分鐘建置，出現綠色勾勾後即可透過指定 URL 訪問。
